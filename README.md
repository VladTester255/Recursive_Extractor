# UniExtract-Recursive-CaseFix

Автоматизированный PowerShell-скрипт для **глубокой рекурсивной распаковки** любых архивов (включая специфичные Linux-форматы) с автоматическим разрешением конфликтов регистра имён файлов в операционной системе Windows.

В качестве движка распаковки скрипт использует мощные возможности [Universal Extractor 2 (gvp9000)](https://github.com/gvp9000/UniExtract2).

## 🚀 Основные возможности

* **Глубокая рекурсия:** Скрипт обходит все вложенные папки, находит архивы внутри уже распакованных архивов и продолжает их извлечение до тех пор, пока не распакует абсолютно всё.
* **Поддержка Linux-архивов:** Корректно обрабатывает специфичные форматы (такие как `.tar`, `.cpio`, `.u-boot.*`), которые часто встречаются в прошивках и образах систем.
* **Решение конфликта регистра (Case-Sensitivity Fix):** Windows по умолчанию нечувствительна к регистру (файлы `Data.txt` и `data.txt` не могут находиться в одной папке). Скрипт автоматически обнаруживает такие конфликты при распаковке Linux-ориентированных архивов и переименовывает файлы, добавляя цифровые приписки во избежание перезаписи и потери данных.
* **Подробное CSV-логирование:** Все результаты работы (успешные распаковки, ошибки, файлы, требующие пароль, битые или пустые архивы) мгновенно записываются в файл `Pass.csv` с сортировкой от новых событий к старым.
* **Изолированная работа:** Каждый архив распаковывается в свою индивидуальную директорию (с префиксом `++`), предотвращая кашу из файлов.

## 🛠️ Требования и подготовка к работе

1. **Движок распаковки:** Скачайте [Universal Extractor 2](https://github.com/gvp9000/UniExtract2).
2. **Структура папок:** Поместите исполняемые файлы UniExtract в папку `UniExtract2` прямо рядом со скриптом:
   ```text
   📁 Recursive_Extractor/
   ├── 📄 Recursive_Extractor.ps1
   └── 📁 UniExtract2/
       └── 📄 UniExtract.exe
   ```
3. **Кодировка:** Сам скрипт должен быть сохранен в кодировке `UTF-8 с BOM` для корректного отображения кириллицы в консоли Windows.

## 💻 Использование

### Способ 1: Через консоль с передачей параметра
Запустите PowerShell и укажите целевую папку, в которой лежат архивы:
```powershell
.\Recursive_Extractor.ps1 -directory "C:\Путь\К\Вашей\папке\С\Архивами"
```

### Способ 2: Интерактивный запуск
Просто запустите скрипт (например, дважды кликнув или выполнив `.\Recursive_Extractor.ps1`). Скрипт сам вежливо попросит вас ввести путь к целевой папке прямо в окне консоли.

## 📊 Структура лога (Pass.csv)

Результаты работы сохраняются в файл `Pass.csv` в кодировке UTF-8 с разделителем `;`. Структура колонок:
`Время; Результат/Причина; ПутьКПапке; ИмяФайла; Расширение`

Лог автоматически обновляется в режиме "Top-Log" — самые свежие события всегда находятся на верхних строчках файла сразу под заголовком.
